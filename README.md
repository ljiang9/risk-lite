# risk-lite 简化版大战略

原创小项目：把 Risk（大战略）桌游压缩到最小可玩形态——12 块领地、2 名玩家、
无卡片、无任务牌，保留骰子战斗、增援、调动的核心循环。纯 Python 标准库。

## 玩法

地图是 3×4 的 12 块领地（北原、雪原……海岸），开局随机平分、每块 2 兵。

每轮三阶段：

1. **增援**：`max(3, 领地数 // 3)` 个兵，自由布署到自己的领地。
2. **进攻**：只能打相邻敌方领地。攻击方掷 `min(3, 兵力-1)` 颗骰，
   防守方掷 `min(2, 兵力)` 颗骰；点数从大到小配对比较，
   **平局算防守方胜**，每对输家减 1 兵。打光守军即占领，
   至少移入进攻所用骰子数的兵力。
3. **调动**：相邻己方领地之间调兵一次（至少留 1 兵守家）。

占领全部 12 块领地者获胜。500 回合未分胜负则按领地数判定（相同为和棋）。

## 用法

```bash
python -m risk_lite                        # 人机对战（你是甲先手，AI 是乙）
python -m risk_lite --auto --games 10 --seed 42   # AI 对战自动演示
```

人机对战命令（领地可用编号 0–11 或中文名）：

- `布 北原 3` —— 增援
- `攻 北原 雪原` —— 进攻
- `移 北原 雪原 2` —— 调动
- `过` / `盘` / `q` —— 结束阶段 / 看棋盘 / 退出

## AI 说明

双方 AI 相同：增援全堆到敌方相邻兵力最多的前线；进攻反复打
"己方兵力明显占优"的战斗（至少 4 兵且多于守军）；调动把内陆多余
兵力集中到最危险的前线。只是贪心启发式，不做多步搜索。

## 已知局限（诚实版）

- **大幅简化**：12 块小地图、无卡片/任务牌、无同盟与谈判，
  不可当作标准 Risk 规则使用。
- AI 只是贪心启发式，不懂多线牵制与兵力集中时机，熟悉规则的人类通常能赢。
- 500 回合上限撞顶时按领地数判胜，实测 AI 对局中从未触发。
- 文本棋盘，无图形界面/存档/悔棋/网络对战；Python 3.10+，纯标准库。
